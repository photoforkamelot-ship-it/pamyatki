# Памятки ОСП

Веб-приложение для подготовки печатных файлов при запуске и сопровождении магазинов. Работает как Telegram Mini App и как обычный сайт. Размещается на GitHub Pages, сборка не нужна.

## Что внутри

| Вкладка | Что делает |
|---|---|
| Памятки / Бланки | Вводные сеанса (город, ОСП, срок, склад, кадровики, ПБ, СБ, управляющий, сотрудники, размен). Памятки из вводных собираются автоматически. Для остальных хранятся PDF, в том числе свой файл на каждый склад, регион или кадровика. |
| Инструкции | Загрузка PDF с датой, общий файл для двусторонней печати с титулом и содержанием. Снятые с печати подсвечиваются жёлтым, при следующем заходе получают плашку «просрочен». Мастер обновления показывает превью и что изменилось в тексте. |
| Сервисный график | Зоны распределяются по функционалам (пекарь, приёмщик, кассир) методом исключения. Показывает нераспределённые зоны, сводную таблицу по сменам и ЯЧЧП (через дробь или по сменам), выгружает в Excel и PDF. |
| Опорный план | Дерево пунктов с отметками «изучено с директором», отдельно для каждого магазина. Можно отметить весь пункт или всё до выбранного. План вставляется списком. |
| Договора | Заметки и PDF по городу: ТКО, дератизация, аренда, ОПС. |
| Деления | Каталог категорий по группам. Высокий или низкий стеллаж, ширина, усиление (+1 деление), архив конфигураций по ОСП и месяцам. Печать — вашим Excel-файлом (лист «ПЕЧАТЬ») или PDF по 1, 2 или 4 карточки на лист. |
| Контакты | Таблица по регионам (СФО, ЦФО, УФО и свои): ФИО, направление, телефон, почта. Любую строку можно изменить, удалить, добавить, скопировать в другой регион. |
| Материалы к открытию | Файлы из общей папки Google Диска по словам в названии (правила выкладки СФО/УФО/ЦФО, 1-й формат, уголок потребителя, письмо о приёмке, «Порядок открытия»). Приложение само проверяет обновления, большие файлы скачивает частями и сжимает. Из «Порядка открытия» собирается список рабочей группы с телефонами. |
| + | Свои вкладки-списки документов. При входе приложение спрашивает про документы, которые не печатались в прошлый раз. |

Настройки (шестерёнка вверху): порядок вкладок (также долгим нажатием на вкладку), скрытие, объединение вкладок, отключение плашек, напоминаний и карандашей, сжатие PDF, Google Диск, резервная копия.

## 0. Стартовый пакет

Рабочие данные хранятся не в коде, а в отдельном файле «Стартовый пакет.json»: контакты, реквизиты, 75 карточек делений, опорный план, 94 зоны и шаблон наклеек. Так они не попадают в открытый репозиторий. Загрузить его можно на вкладке «Памятки» или в «Настройки → Данные». На каждом новом устройстве пакет загружается один раз, а с подключённым Google Диском данные подтягиваются сами.

## Word-шаблоны

В пункт «Наклейки» загружается файл .docx с метками. Приложение подставляет значения и выдаёт готовый Word-файл. Метки:
`{{ОСП}}`, `{{ГОРОД}}`, `{{АДРЕС}}`, `{{УПРАВЛЯЮЩИЙ}}`, `{{ТЕЛЕФОН}}`, `{{СКЛАД}}`, `{{РЕГИОН}}`, `{{ДАТА}}`, `{{СОТРУДНИК1}}`…`{{СОТРУДНИК12}}`. Первый сотрудник — это управляющий, дальше идут сотрудники из вводных.
Метку набирайте целиком, без изменения шрифта внутри неё. Так же можно загрузить .docx в любую вкладку-список: при печати он придёт заполненным отдельным файлом.

## 1. Размещение на GitHub Pages

1. Создайте репозиторий, например `pamyatki`, и загрузите в него все файлы из этой папки.
2. Откройте **Settings → Pages**, в разделе **Source** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/pamyatki/`.

## 2. Telegram Mini App

1. В [@BotFather](https://t.me/BotFather) создайте бота командой `/newbot` и сохраните токен.
2. Командой `/mybots` → ваш бот → **Bot Settings → Menu Button** укажите адрес сайта с GitHub Pages. Кнопка приложения появится в чате с ботом.
3. Напишите боту `/start`. Без этого бот не сможет присылать вам файлы.

## 3. Google Диск через Apps Script (рекомендуется)

Нужен, чтобы файлы не потерялись при очистке Telegram или браузера, синхронизировались между телефоном и компьютером, а готовые PDF приходили прямо в чат.

1. Откройте [script.google.com](https://script.google.com) и создайте проект.
2. Замените содержимое `Code.gs` текстом из `apps-script/Code.gs`.
3. В **Настройках проекта → Свойства скрипта** добавьте:
   - `SECRET` — любой длинный пароль;
   - `BOT_TOKEN` — токен бота;
   - `ALLOWED_IDS` — ваш Telegram ID, если хотите заходить из Telegram без ключа (необязательно).
4. Выберите **Развернуть → Новое развертывание → Веб-приложение**. Параметры: «Выполнять как: я», «Доступ: все». Подтвердите доступ к Диску.
5. Скопируйте адрес, который заканчивается на `/exec`, и вставьте его в приложении: **Настройки → Google Диск**. Туда же введите `SECRET` и нажмите «Проверить».

Скрипт хранит файлы приложения в папке «Памятки ОСП» на вашем Диске. Для вкладки «Материалы к открытию» и памятки сотрудникам он ещё читает (только читает) указанные папки и файлы, к которым у вашего аккаунта есть доступ. Пользоваться им можно только с ключом или из Telegram-аккаунта из `ALLOWED_IDS`, а подпись Telegram проверяется токеном бота.

После изменения `Code.gs` создайте новую версию развертывания (**Управление развертываниями → Изменить → Новая версия**), иначе останется старый код.

### Условия показа документов

У документа может быть условие: регион, склад (РЦ) или город. Если магазин не подходит, документ показывается серым и не печатается: например, журнал электрощитовых — только ЦФО, бланк МОПов — только РЦ Обухово, препроводительная ведомость Алтайского ОСБ — только Барнаул и Алтайский край. Склад выбирается сам: город Омск или код ОСП на «О» (О120, О010) — РЦ Омск.

## Как устроено

- Данные и PDF хранятся в браузере (IndexedDB). При подключённом Диске копия уходит туда.
- Сжатие при загрузке: бережное (без потерь) для текстовых файлов. Тяжёлые сканы в режиме «Авто» пересобираются в 200 dpi, этого достаточно для печати.
- Двусторонняя печать: каждый документ добивается пустой страницей до чётного числа, поэтому следующий всегда начинается с нового листа. Печатайте с переворотом по длинному краю.
- Страницы, которые приложение составляет само (титул, содержание, памятки из вводных, карточки делений), рисуются шрифтом DejaVu Sans в 200 dpi.

Библиотеки лежат в `vendor/`: [pdf-lib](https://github.com/Hopding/pdf-lib) (MIT) и [PDF.js](https://github.com/mozilla/pdf.js) (Apache 2.0). Шрифт DejaVu лежит в `fonts/` (свободная лицензия).

## Ограничения

- Внутри Telegram на части устройств нельзя скачать файл напрямую. Для этого и нужна отправка в чат через Google Диск.
- Бот отправляет файлы до 50 МБ. Большие сборки разбивайте по разделам.
- Содержимое ваших памяток и бланков приложение не знает. Загрузите свои PDF в соответствующие пункты.
